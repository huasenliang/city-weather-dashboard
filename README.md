# 城市天气数据工作台

一个用来比较中国城市历史天气的交互式网页。你可以在地图上选择城市，按需从 Open-Meteo 获取逐日数据，比较同一时期各地的气温变化、昼夜温差和累计降水。后端使用 Python 标准库，前端使用原生 JavaScript 和 ECharts。

## 用北京和广州试一次

1. 打开首页，在地图或城市列表中选中北京和广州。也可以通过搜索框添加城市，每次最多比较 5 座。
2. 选择 **30 天**，点击 **抓取数据**。首次进入页面时，结果区会提示你先选城市。
3. 在主图选择 **日平均气温**，移动鼠标可以读取两座城市在同一天的温度。切换到 **降水量** 可以看哪天下过雨，查看下方的 **累计降水** 可以比较整个时段的雨量。
4. 想比较昼夜温差时，查看日较差分布。想知道两地气温是否同步升降时，查看气温相关矩阵。页面右上角可以切换中英文和深浅色主题。

## 导出采集结果

抓取完成后，点击 **下载逐日 CSV**，即可在 Excel 中按城市和日期查看日平均、最高、最低气温、日较差及降水量。点击 **下载实验报告（HTML）** 可保存含采集区间、缺测处理数量、分城市统计和四张图表的独立报告。用浏览器打开报告即可离线阅读，或打印为 PDF。每张图表下方也有 **下载图表 PNG** 按钮。

## 本地运行

安装 Python 3.10 或更高版本，下载或克隆仓库，在包含 `server.py` 和 `render.yaml` 的目录运行以下命令。服务使用 Python 标准库，无需安装第三方包。

```bash
python server.py
```

启动后打开[本地天气工作台](http://127.0.0.1:8848)。如需更换端口，可以运行 `python server.py --port 9000`。抓取新数据时需要联网。

## 部署到 Render

1. 登录 [Render 控制台](https://dashboard.render.com/)，选择 **New → Blueprint**。
2. 连接存放本项目的 GitHub 仓库，选择包含 `render.yaml` 的分支。如果文件位于仓库根目录，Blueprint Path 填 `render.yaml`。
3. 在预览中核对服务名 `city-weather-dashboard` 和套餐，然后确认部署。仓库中的配置会启动 `python server.py`，并通过 `/api/health` 检查服务状态。
4. 服务显示 **Live** 后，打开服务页面给出的公网网址。把这个网址发给同学，他们就能用浏览器查看和比较天气。

## 数据来源与读图说明

- **时间范围**可选 7、30 或 90 天。默认截止日期为运行当天往前推 5 天，以避开归档延迟。逐日数据按北京时间（`Asia/Shanghai`）汇总。
- **气温和降水**来自 Open-Meteo 的网格再分析数据，代表城市坐标所在网格的天气状况。气温单位为 °C，降水单位为 mm，日较差等于当日最高气温减去最低气温。[Open-Meteo 历史天气数据说明](https://open-meteo.com/en/docs/historical-weather-api)
- **缺测与缓存**会影响读数。系统会尝试补齐缺失气温，缺失降水按 0 处理。同一查询的结果缓存 6 小时，可以使用强制重抓选项重新请求。页面底部的「采集血缘」记录请求地址和原始响应的 SHA-256 摘要，便于核对数据来源。

## 主要文件

| 文件 | 用途 |
| --- | --- |
| `server.py` | 提供网页及城市搜索、天气采集、统计与缓存接口 |
| `index.html` | 工作台首页 |
| `assets/app.js` | 地图选城、数据请求、图表和表格交互 |
| `assets/ui.js`、`assets/style.css` | 中英文文案、主题与页面样式 |
| `assets/vendor/` | 随项目提供的 ECharts、地图、城市坐标和字体 |
| `render.yaml` | Render 服务配置 |
